# Amira Restaurant Website

A fully responsive, multi-page website built for Amira Restaurant as a web development project.

## Project Pages
- **index.html**: Homepage featuring header, hero banner, and primary call to action.
- **menu.html**: Restaurant food menu designed using CSS Grid.
- **about.html**: Information about Amira Restaurant, mission, and ingredients.
- **contact.html**: Interactive contact form for customers.

## Technologies Used
- **HTML5**: Semantic tags and site structure.
- **CSS3**: Custom styling, Flexbox navigation, CSS Grid menu layout, and Media Queries for responsiveness.
- **Git & GitHub**: Version control tracking progress across multiple commits.

## Features
- Clean and modern navigation with hover states.
- Fully responsive across Desktop, Tablet, and Mobile devices.
- Pure HTML/CSS without external frameworks.
