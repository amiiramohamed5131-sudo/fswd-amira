# Halane Restaurant Website

A fully responsive, multi-page website built for Halane Restaurant as a web development project.

## Project Pages

- **index.html**: Homepage featuring header, hero banner, SEO meta descriptions, and primary call to action.
- **menu.html**: Restaurant food & drink menu designed with responsive cards and active direct image links.
- **about.html**: Information about Halane Restaurant, mission, ingredients, and operating hours.
- **contact.html**: Interactive contact form for customers.

## Technologies Used

- **HTML5**: Semantic tags and site structure.
- **Tailwind CSS**: Modern styling, grid layout, and responsiveness.
- **Git & GitHub**: Version control tracking progress across multiple commits.

## Features

- Clean and modern navigation with hover states.
- Fully responsive across Desktop, Tablet, and Mobile devices.
- High quality direct image links for foods and drinks.
